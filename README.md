# 🧠 Cartera de Proyectos de Aprendizaje Automático

Este repositorio contiene una plataforma web desarrollada, cuyo propósito es demostrar la aplicabilidad de diversas técnicas de **Inteligencia Artificial** como *Naive Bayes*, *Redes Neuronales*, *Algoritmos Genéticos*, *NLP* y *Transfer Learning*.

## 🧠 Funcionalidades destacadas

- Predicción de gama de celulares (Naive Bayes)
- Predicción de diabetes (Red Neuronal)
- Clasificación de imágenes de platos típicos (Transfer Learning)
- Simulación de Algoritmo Genético (Optimización)
- Clasificación automática de incidentes informáticos con BERT/BETO (NLP)

## 🚀 Tecnologías utilizadas

### 🔙 Backend
- Python 3.10+
- FastAPI
- Scikit-learn
- Uvicorn
- Joblib, NumPy

### 🔜 Frontend
- React (con Vite)
- Node.js 18+
- npm 9+
